## 一、「稳定」怎么判断

先说一件反直觉的事：**网上那些「XX 云 45ms」的榜单，你不该信。**

延迟是高度个人化的指标。同一个香港节点，在深圳电信和在北京联通测出来能差一倍以上，
晚高峰和凌晨又是两个数。任何一份速度榜单，测的都是**作者自己那条宽带**——
那个数字对他成立，对你不一定。

所以这份清单换了个做法：**只比不因你在哪而改变的东西**，再教你自己测。

### 1. 线路类型（结构性差异，可查证）

| 类型 | 特征 | 稳定性预期 |
| :--- | :--- | :--- |
| **IPLC** | 全程走运营商内网，不经公网国际出口 | 带宽通常独享或准独享，波动最小 |
| **IEPL** | 同样走内网，但多为共享带宽 | 晚高峰有小幅波动 |
| **BGP + 专线出口** | 国内三网择优 + 出境专线 | 入口体验好，出境取决于专线质量 |
| 中转 / 直连 | 经过公网 | 受国际出口拥塞影响明显 |

⚠️ **CN2 / CUII / CMI 是优化公网路由，不等于 IPLC 或 IEPL。**
部分商家会混着写，看到这几个词不要当成专线。

### 2. 运营年限（跑路风险的最强信号）

这个行业商家更替频繁。运营时间短不代表不可靠，但它意味着**可参考的记录少**。
本清单里运营时间最短的一家只有约半年，[档案页](https://www.clashnodes.net/brands/shanyue)里如实标注了。

**对任何新品牌，做法都一样：先买月付验证一个月，不要一上来就买年付或终身套餐。**

### 3. 客户端是否被锁死

这条最近变得重要。本站在采集数据时发现，已经有品牌**关闭了通用订阅链接**：

| 品牌 | 情况 |
| :--- | :--- |
| [光年梯](https://www.clashnodes.net/brands/guangnianti) | 官方公告已关闭通用订阅链接，暂不支持第三方开源客户端 |
| [一翻云](https://www.clashnodes.net/brands/yifanyun) | 后台标注客户端为自研 |
| [宇宙云](https://www.clashnodes.net/brands/yuzhouyun) | 后台只写「自研客户端」，未说明是否提供通用订阅 |

如果你依赖 Clash 的规则分流，**买之前必须确认能不能拿到标准订阅链接**——
拿不到的话，Clash / Shadowrocket / v2rayN 一个都用不上。

### 4. 自己测三分钟

```bash
# 连上节点后跑满 100 个包，看丢包率和最大最小值差值
ping -n 100 目标地址        # Windows
ping -c 100 目标地址        # macOS / Linux
```

- **必须测晚高峰**（21:00–22:30），白天数据没有参考价值
- **连测三天**，单次可能碰上偶发波动
- **抖动比平均延迟更重要**——平均 60ms 但抖动 50ms，实际体验差于稳定在 90ms

完整方法见[低延迟专项](https://www.clashnodes.net/rankings/latency)。

## 四、常见问题

### 为什么这份清单没有测速数据？

因为速度和延迟高度依赖你所在的城市与运营商，别人测的数换到你家未必成立。
本站不发布未经自己测量的数字，也不转载来源不明的第三方排名与评分。
替代做法是比可核实的结构性差异，并提供[自测方法](https://www.clashnodes.net/rankings/latency)。

### 这份榜单收钱吗？

**收。** 上表的排序是按合作关系指定的商业推荐位，本站从成交中获得佣金。
这一点写在表格上方，也写在[关于本站](https://www.clashnodes.net/about/)的利益披露里。

不受商业因素影响的部分是：[选购决策器](https://www.clashnodes.net/tools/)不读取任何佣金字段，
单 GB 换算是公开公式，上面那份停运名单里也包括曾经的合作方。

### 买月付还是年付？

**第一次一律先买月付。** 用满一个月确认自己所在地区和运营商的实际表现，
稳定后再考虑长期。这个行业商家更替频繁，预付整年等于把跑路风险全部自己承担。

判断年付是否划算要比**单 GB 成本**，不能只比月均金额——
有的商家在年付档同时下调了流量额度。

### 怎么自己核对这些数据？

每个品牌的[档案页](https://www.clashnodes.net/brands/)都标注了数据来源（官方后台采集 / 商家提供资料）
与采集日期，套餐明细逐档列出，单 GB 换算公式写在页面上。
发现与实际不符，欢迎[反馈](https://www.clashnodes.net/contact/)。
